# FamilyArchive 🌳

Семейный архив и интерактивное генеалогическое древо на Flask и SQLite.

---

## 🚀 Инструкция по запуску (для друга)

### 1. Требования
- Установленный Python версии 3.10 или новее.

### 2. Клонирование и установка зависимостей
Откройте терминал (командную строку или PowerShell) и выполните:

```bash
git clone <ССЫЛКА_НА_РЕПОЗИТОРИЙ>
cd FamilyArchive
pip install -r requirements.txt
```

### 3. Запуск приложения
```bash
python app.py
```

После этого откройте браузер и перейдите по адресу:
👉 **[http://127.0.0.1:5000](http://127.0.0.1:5000)**
